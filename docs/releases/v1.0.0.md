# EvalForge v1.0.0

EvalForge v1.0.0 is a deterministic, provenance-first toolkit for evaluating
recorded AI-system outputs. It preserves non-success cases in denominators,
supports paired uncertainty and slices, measures human-label agreement, and
calibrates strict recorded-judge decisions without making live provider calls.

## Included

- Bounded, versioned dataset, candidate, human-label, and judge-record schemas.
- Deterministic evaluation, comparison, consensus, agreement, and calibration.
- Independent replay for every public report artifact.
- Explicit missing, error, timeout, truncation, abstention, tie, and
  insufficient-evidence states.
- Offline CC0 synthetic fixtures and checked SHA-256 release evidence.
- Reproducible wheel and canonical sdist verification with isolated installation.

## Verification

CI supports Python 3.11, 3.12, and 3.13. Each job runs lint, formatting, strict
typing, tests, demo/evidence regeneration, two package builds, archive-policy
checks, an offline isolated-wheel smoke test, dependency consistency, and a
known-vulnerability audit.

## Important limits

This release does not provide live inference, a model leaderboard, a sandbox,
artifact signing, authenticated provenance, encryption, access control, an
adjudication workflow, or production telemetry. Synthetic report values are not
model benchmarks. Agreement and bootstrap intervals do not establish dataset
validity, representativeness, fairness, or causal effects.
