# Roadmap

## v0.1: deterministic foundation

- [x] Provenance-first dataset and candidate schemas.
- [x] Exact, substring, and strict JSON evaluation.
- [x] Explicit missing/error/timeout semantics.
- [x] Canonical report lineage and independent replay.
- [x] Synthetic fixtures, tests, CI, packaging, and design documentation.

## v0.2: comparison methodology

- [x] Paired run comparison with explicit case alignment.
- [x] Seeded bootstrap intervals and minimum sample warnings.
- [x] Slice definitions that preserve denominators and provenance.
- [x] Regression policy without arbitrary “quality” claims.

## v0.3: judge research

- [ ] Human-label schema and inter-rater agreement evidence.
- [ ] Calibrated judge adapters with prompt-injection boundaries.
- [ ] Cost, retry, truncation, and provider-version lineage.

No live integration is accepted before its privacy and failure model is tested.
